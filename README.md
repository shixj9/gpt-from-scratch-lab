# GPT From Scratch Lab

## 1. Introduction | 项目简介

本项目使用 **PyTorch 从零构建字符级 GPT 语言模型**，按照 **v0 → v5** 的顺序逐步完善网络结构，通过模型训练、文本生成和实验结果对比，理解语言模型的基本原理以及 Decoder-only Transformer 的核心组成。

项目主要参考 Andrej Karpathy 的 [Let's build GPT: from scratch, in code, spelled out](https://www.youtube.com/watch?v=kCc8FmEb1nY) 教学视频。

各版本使用 **Tiny Shakespeare** 数据集，采用字符级 Tokenization，以预测下一个字符为训练目标。每个版本的训练配置、损失指标与生成样本分别保存在 `results/` 对应目录下。

## 2. Learning Map | 模型学习与实现

### v0 — Bigram Language Model

**模型简介**

项目的起点。模型只根据当前字符预测下一个字符，通过学习相邻字符的统计关系，建立最基础的自回归语言模型。

**核心功能**

- 将字符转换为 Token ID，并建立可学习的下一字符预测分布。
- 使用交叉熵损失和梯度优化训练模型。
- 根据预测概率逐字符采样，完成自回归文本生成。

**版本意义**

建立完整的“数据处理 → 模型训练 → 文本生成”实验流程，作为后续版本的比较基线。

### v1 — Single-Head Self-Attention Language Model

**相较 v0 的新增与改进**

- **引入单头因果自注意力**：预测时不再只依赖当前字符，还可以根据注意力权重综合窗口内之前的字符信息。
- **引入位置编码**：在字符内容特征之外加入位置信息，使模型能够区分序列中不同位置的字符。
- **引入因果掩码**：确保每个位置只能访问自己及之前的字符，符合自回归预测要求。

**版本意义**

从相邻字符的直接预测，过渡到基于历史上下文的信息聚合，建立注意力语言模型的基本结构。

### v2 — Multi-Head Self-Attention Language Model

**相较 v1 的新增与改进**

- **单头升级为多头注意力**：由一个注意力头扩展为四个参数独立的注意力头。
- **学习多种信息关联方式**：不同注意力头可以分别学习不同的字符匹配关系和上下文聚合模式。
- **整合多头特征**：将各注意力头的结果拼接为统一的特征表示，供后续预测使用。

**版本意义**

使模型能够从多个注意力模式中提取上下文信息，增强对不同字符关系的建模能力。

### v3 — FeedForward Network

**相较 v2 的新增与改进**

- **引入前馈神经网络（FFN）**：在多头注意力完成上下文聚合后，进一步加工每个字符的特征表示。
- **增加非线性特征变换**：先扩展特征维度，再通过非线性激活和线性映射恢复原维度，以学习更复杂的特征组合。
- **明确两类计算的分工**：注意力负责字符之间的信息交流，前馈网络负责逐字符的特征加工。

**版本意义**

在上下文聚合之外加入非线性表示变换，使模型具备 Transformer 中注意力与前馈计算的基本组合。

### v4 — Residual Connections & Layer Normalization

**相较 v3 的新增与改进**

- **引入残差连接（Residual Connection）**：将子层计算结果与输入特征相加，为信息和梯度提供直接传播路径。
- **引入层归一化（LayerNorm）**：分别在多头注意力和前馈网络之前归一化每个字符的特征，帮助稳定训练。
- **形成单个 Transformer Block**：将多头注意力、前馈网络、残差连接与层归一化整合为一个可复用的 Pre-LN 模块。

**版本意义**

从简单串联的注意力与前馈网络，发展为结构完整、便于进一步堆叠的 Transformer Block。

### v5 — Multi-Layer Decoder-only GPT & Scaling Up

**相较 v4 的新增与改进**

- **堆叠多个 Transformer Block**：由单层扩展为六层，使字符表示能够经历多轮上下文聚合和特征加工。
- **扩大模型宽度**：特征维度从 32 提升至 384，注意力头数从 4 增加至 6，前馈网络的中间维度提升至 1536。
- **扩大上下文窗口**：从 8 个字符扩展至 256 个字符，使模型能够利用更长的历史文本进行预测。
- **完善多头注意力输出**：增加输出特征投影，使不同注意力头的结果能够进一步混合。
- **增强训练配置**：加入 Dropout 和最终层归一化，并调整学习率、批量大小与训练步数，以适应更大的模型。

**版本意义**

构建拥有约 **1079 万个参数**的多层字符级 Decoder-only GPT。生成文本已能模仿莎士比亚戏剧的人物名称、对话排版和部分英文句式。

**当前模型的局限性**

- **数据规模与领域有限**：仅使用 Tiny Shakespeare 进行训练，文本风格主要集中在莎士比亚戏剧语料。
- **仍采用字符级 Tokenization**：模型逐字符生成，难以直接利用更高层次的词语或子词表示。
- **生成质量仍有限**：虽然对话格式和局部句式明显改善，但仍可能出现语法错误、语义跳跃和不连贯内容。
- **存在一定过拟合迹象**：最终训练损失与验证损失之间存在较明显差距；更大模型的效果也受到数据规模与训练配置限制。

## 3. Experiments | 实验结果

以下为各版本**单次实验**的最终结果，Loss 越低代表当前评估下的下一字符预测误差越小。

| Version | Model | Train Loss | Validation Loss |
|---|---|---:|---:|
| v0 | Bigram | 2.4613 | 2.4897 |
| v1 | Single-Head Self-Attention | 2.4156 | 2.4231 |
| v2 | Multi-Head Self-Attention | 2.2213 | 2.2798 |
| v3 | FeedForward Network | 2.1397 | 2.2138 |
| v4 | Residual Connections & LayerNorm | 2.0782 | 2.1684 |
| **v5** | **Multi-Layer Decoder-only GPT** | **1.0502** | **1.4896** |

随着版本迭代，当前实验中的验证损失整体下降。需要注意，**v5 同时调整了模型规模、上下文长度和训练配置**，因此它与 v4 的差异不能归因于单一结构改动。

各版本的详细训练配置和生成文本可分别查看 `results/v0/` 至 `results/v5/` 目录中的 `metrics.md` 与 `sample.txt`。
